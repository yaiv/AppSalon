# 💇‍♀️ App Salón de Belleza

Esta es una aplicación web construida con PHP y MySQL para gestionar los servicios de un salón de belleza. Permite mostrar los servicios disponibles en el salón para que los clientes puedan elegirlos fácilmente.

## 📌 Funcionalidades

- Visualización de servicios desde una base de datos.
- Interfaz limpia y responsive usando HTML y CSS personalizados.
- Arquitectura basada en archivos PHP modulares.

## 🧰 Tecnologías utilizadas

- **PHP** – Lógica del lado del servidor.
- **MySQL** – Base de datos para almacenar los servicios.
- **HTML5 / CSS3** – Maquetación y estilos.
- **Google Fonts** – Fuente personalizada.
- **JavaScript** - Interactividad del sitio. 

## ⚙️ Requisitos.

- Servidor local (como XAMPP, MAMP o WAMP).
- PHP 7.x o superior.
- MySQL.
- Navegador web moderno.

🚀 Cómo ejecutar el proyecto
Clona este repositorio o descarga los archivos.

Coloca la carpeta en el directorio de tu servidor local (por ejemplo, htdocs en XAMPP).

Crea la base de datos y la tabla de servicios.

Abre tu navegador y accede a http://localhost/AppSalon_PHP.
